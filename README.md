# Гамаюн

Сайт и цифровая платформа гончарной мастерской «Гамаюн».

## План проекта

- Главная страница и визуальная концепция
- Каталог мастер-классов
- Календарь и бронирование
- Регистрация и личные кабинеты
- Онлайн-оплата
- Магазин керамики
- Корзина и доставка
- Админ-панель
- Касса и отчёты

Проект развивается поэтапно в одном репозитории.
