# Гамаюн Керамика

Фронтенд сайта керамической мастерской в Смоленске. Это статический сайт без сборки: его можно открыть локально или опубликовать на GitHub Pages.

## Страницы

- `index.html` — главная;
- `booking.html` — выбор направления;
- `calendar.html?type=wheel` — календарь и выбор времени.

Поток записи построен на обычных ссылках, поэтому не зависит от JavaScript-переходов. Календарь использует FullCalendar 7 Standard через CDN; занятые слоты пока демонстрационные.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и загрузите содержимое этой папки.
2. В **Settings → Pages** выберите публикацию из ветки `main`, папка `/ (root)`.
3. После появления адреса замените временные телефон и email в `index.html`.

## Перед запуском бронирования

Нужно согласовать финальные цены, контакты, политику обработки персональных данных и выбрать сервис базы данных/бронирования. Затем можно подключить Supabase для общих слотов и настоящих заявок.
